# 词根双数据源交叉校验报告

> 生成：2026-09-01 · 工具：`npx tsx scripts/xcheck-merge.ts`（合并三路分报告）
> 机器可读产物：`public/data/xcheck-report.json` · 分报告：`public/data/xcheck-{etymwn,wiktionary,etymonline}.json`
> 原则：所有结论逐条可溯源到 `.cache/` 开源数据原文，禁止编造；confirmed 是「有实证的下界」而非 truth。

## 一、结论总览

| 指标 | 数值 |
|---|---|
| 校验词根 | **569**（enhanced-roots.json 全量） |
| **confirmed（有词源实证）** | **342（60.1%）** |

| 抽样词 | 1134（每词根 ≤2，三源同一抽样器） |
| 词义机判 | match 53 · **mismatch 32** · unverified 1049（桥表覆盖 core36+middle24） |

分层看（confirmed / not_found / conflict）：

| 层 | confirmed | not_found | conflict |
|---|---|---|---|
| core（36） | **29（80.6%）** | 7 | **0** |
| middle（101） | 77（76.2%） | 22 | 2 |
| edge（432） | 236（54.6%） | 134 | 62 |

**核心结论：学习主路径（core + middle，137 词根）中 106 个（77.4%）拿到独立开源词源实证，conflict 仅 2 个，0 个在核心层。** 词根库的主体质量得到三源交叉支持。

## 二、三个数据源

| 源 | 文件 | 形态 | 词根命中（conf/nf/cf） | 特点 |
|---|---|---|---|---|
| Etymological Wordnet | `.cache/etymwn-etymologies.json`（98MB） | 词源关系图（无向，2013-02-08，CC BY-SA） | 249 / 250 / 70 | 覆盖广但丢方向、无 PIE 键 |
| Wiktionary 转码 | `.cache/ety-wiktionary-etymologies.json`（15MB） | 有向谱系（派生词→词源词，CC BY-SA/GFDL） | 236 / 290 / 43 | 方向真实但中间形态稀疏 |
| etymonline 镜像 | `.cache/etymonline-index.json`（19MB） | 词源叙述文本（46840 词条） | 304 / 258 / 7 | 唯一含英文 gloss，文本启发式抽取 |

三源判定规则一致：古典语（拉丁/希腊）强度≥2 形态命中≥1，或罗曼语（法语等传播路径）强度≥2 命中≥2。合并取任一源最高结论，单源 not_found 视为覆盖缺口不拉低结论。

## 三、人工复核重点

### 1. core/middle 层 conflict（2 个，最高优先级）

| 词根 | 层 | 源 | 情况 |
|---|---|---|---|
| **able** | middle | etymwn | 抽样词词源链指向非古典；拉丁 habere 线索在本数据集未被记录 |
| **arm** | middle | etymwn, wiktionary | eng:arm → enm:arm → ang:earm（日耳曼同形词路径）；拉丁 arma 分支在数据中缺失。arm 武器义两个语源并存，建议人工定夺词库释义表述 |

### 2. 词义机判 mismatch（32 条，全量见 JSON `words[*].meaningVerdict==='mismatch'`）

机判从严（gloss 词干与桥表关键词无交集即判 mismatch），**不等于词库错误**，样例：

| 词根 | 词库义 | etymonline gloss（节选） | 初判 |
|---|---|---|---|
| act | 做，行动 | act "(official) document" | gloss 只列了次要义，非错误 |
| ceed | 走 | succeed "go, move" | go 即「走」，桥表缺 go→误报候选 |
| sent | 感觉 | absent "be away from" | 「离开」与「感觉」确需人工核对 |
| vis | 看 | visible "perceptible" | perceptible≈可见，桥表缺词导致误报 |

建议：把这 32 条过一遍，多数应为「桥表关键词补词」，少数可能是词根释义需要校准。

### 3. core 层 not_found（7 个）

`at / as / ition / her / as` 为同化前缀/形态类部件（本无公认古典语源，符合预期）；`sur / sid / mon` 抽样词在数据集覆盖缺口，可后续换代表词复跑。

### 4. edge 层 conflict（62 个）

绝大多数是 know/land/work 类日耳曼本源基础词——应解读为「这些词根本非拉丁/希腊词源」，与机械切分产生的伪词根现象一致，属数据清洗信号而非词库错误。

## 四、已知结构性缺口（影响 confirmed 数量偏保守）

1. etymwn/wiktionary 转码均无 `p_ie/p_lat/p_grc` 顶层键 → PIE 层证据整体缺失
2. 希腊形态为希腊字母原文（γράφω），a-z 归一后为空串 → 希腊词根证据偏少
3. etymonline 为叙述文本正则抽取，引号不紧跟的形态会漏采（如 visionem 后跟括注时只采到 visio）
4. 部分常用词（experience/visible 等）在转码数据中未收录

## 五、复现方式

```bash
# 数据下载指引见各运行器报错提示与 docs/kaoyan-vocab.md；.cache/ 已 gitignore
npx tsx scripts/xcheck-etymwn.ts       # 路一：98MB 关系图，流式 4 轮 BFS
npx tsx scripts/xcheck-wiktionary.ts   # 路二：15MB 有向谱系
npx tsx scripts/xcheck-etymonline.ts   # 路三：19MB 叙述文本 + 词义机判
npx tsx scripts/xcheck-merge.ts        # 合并 → public/data/xcheck-report.json
```

测试：`npx vitest run`（合并规则与三路解析均有 fixture 测试，不依赖 .cache 与网络）。
